YCollector는 yt-dlp 코어 위에 Tauri + React + shadcn/ui 데스크톱 앱을 올린 YouTube 다운로더입니다. URL을 붙여넣고, 설정은 우측 슬라이드 패널에서 버튼으로, 완료 항목은 라이브러리 탭에서 검색하세요.

3개 레이어 · 1개 사이드카 · 0개의 마이크로서비스

0사전 요구사항

Windows 11 기준. 모든 도구는 winget 한 줄로 설치할 수 있습니다.

Python 3.11+

uv가 .venv를 자동 생성합니다. 3.13 권장.

# winget
winget install Python.Python.3.13

uv (Python 패키지 매니저)

pip보다 10~50배 빠릅니다.

winget install astral-sh.uv

Node.js 18+ & pnpm

프런트엔드 빌드용. npm으로도 OK.

winget install OpenJS.NodeJS.LTS
npm i -g pnpm

Rust 1.77+

Tauri 쉘 컴파일용. 첫 빌드는 5~10분.

winget install Rustlang.Rustup
rustup default stable

WebView2 Runtime

Windows 11은 기본 포함. 10은 Edge 페이지에서.

# Windows 11 → 이미 있음
# 확인:
winget list Microsoft.EdgeWebView2

FFmpeg

DASH 비디오/오디오 머지에 필수.

winget install Gyan.FFmpeg

15분 설치 (한 번만)

위 도구를 다 설치한 상태에서.

저장소 클론
git이 없으면 winget install Git.Git로 먼저 설치.
git clone https://github.com/dalyulbam/YCollector.git
cd YCollector
Python sidecar 의존성
uv가 .venv를 만들고 yt-dlp + ycollector를 설치합니다.
uv sync
프런트엔드 의존성
React + Tailwind + shadcn + Tauri-cli. 처음에 100MB 정도 받습니다.
pnpm --dir frontend install
# pnpm 없으면:  cd frontend ; npm install ; cd ..
(선택) Tauri CLI 전역 설치
위 pnpm install로 frontend에 이미 들어 있지만, 글로벌 cargo tauri를 쓰고 싶다면.
cargo install tauri-cli --version "^2.0"

2개발 모드 (HMR 가동)

터미널 하나면 됩니다. Tauri가 Vite를 자식으로 띄우고, Rust가 PATH의 ycollector를 sidecar로 spawn합니다. 

# uv sync 가 만든 .venv 가 활성화돼있는 셸에서:
cd src-tauri
cargo tauri dev

가동 시퀀스

최초 1회: Cargo 의존성 컴파일 ~5–10분. 이후는 수 초.

확인 포인트

  • 창 우상단에 yt-dlp <버전> 표시 → sidecar 가동 OK
  • URL 붙여넣고 Enter → 잠시 후 썸네일/제목이 나타나면 NDJSON 왕복 OK
  • ⚙ 설정 → 화질 변경 → 저장 → CLI에서 uv run ycollector ...도 같은 설정 사용 (%APPDATA%\YCollector\settings.ini 공유)

3프로덕션 빌드 (.msi / .exe 인스톨러)

한 줄 스크립트로 4단계 자동화.

.\scripts\build_tauri.ps1
# 산출물: src-tauri/target/release/bundle/{msi,nsis}/

파이프라인

build_tauri.ps1이 위 4단계를 직렬 실행.

옵션

플래그설명
-SkipSidecar이미 src-tauri/binaries/에 sidecar가 있으면 1~2단계 스킵
-Triple <triple>기본 x86_64-pc-windows-msvc. arm64 등 크로스 빌드 시

번들 크기 비교

대략적 추정. WebView2 런타임은 OS 제공이라 별도 다운로드 없음.

4트러블슈팅

자주 만나는 7가지 함정.

CMDcargo: command not found
Rust 미설치. winget install Rustlang.Rustup 후 새 터미널에서 rustup default stable.
CMDtauri: command not found (cargo는 있음)
tauri-cli 미설치. cargo install tauri-cli --version "^2.0" 또는 pnpm --dir frontend install 후 pnpm --dir frontend tauri dev.
SPAWNsidecar spawn 실패
venv 미활성화. 같은 터미널에서 uv sync 했는지 확인하거나 uv pip install -e .로 PATH 등록.
UI창은 뜨지만 yt-dlp 버전 배지 없음
sidecar가 죽음. F12 DevTools → Console에서 job:log 이벤트 추적. 시스템에 yt-dlp 또는 FFmpeg가 없는지 확인.
ENC한글 제목이 ❑로 깨짐
Windows cp949 콘솔 문제. cli.py와 sidecar가 UTF-8 강제하므로 최신 커밋 사용. 그래도 깨지면 chcp 65001.
NPMEPERM on pnpm install
OneDrive 등 동기화 폴더와 충돌. node_modules를 동기화 제외하거나 저장소를 동기화 밖으로 이동.
HANG다운로드가 "준비 중…"에서 멈춤
yt-dlp가 deno(JS 런타임) 대기. winget install DenoLand.Deno 후 새 터미널. 이미 winget으로 설치했어도 PATH가 누락된 경우, sidecar가 자동 fallback 폴더를 검색합니다.

8영상 생성 — Sora 2 Pro

OpenAI Videos API (POST /v1/videos). Provider 추상화로 후속 모델 교체 용이. 2026-09-24 sunset 예정 — 본 통합은 시한부, 그 전까지 PoC/실험용.

두 가지 진입점

CLI

ycollector-generate. 자동화·배치·CI에.

uv run ycollector-generate "고양이가 비를 맞으며 우산을 들고 걷는 장면" \
  --references "https://www.youtube.com/watch?v=..." \
  --model sora-2-pro --size 1280x720 --seconds 8 \
  --out generated/cat.mp4 --budget-usd 5

로컬 서버 UI

참조 URL과 프롬프트를 리스트로 쌓아가며 한 번에 N개 생성. 진행률은 SSE.

uv run ycollector-server
# → http://127.0.0.1:8765/ 의 §2 패널

가격표 (2026-05 OpenAI 공식)

$2.40 (UI 기본) sora-2-pro · 1024×1792 $0.50/s 8s 영상 = $4.00 sora-2-pro · 1080p $0.70/s 8s 영상 = $5.60 (8s × 20s 풀이면 $14)
CLI는 --budget-usd, UI는 클릭 직전 confirm() 으로 비용 가드.

reference 처리

YouTube URL을 reference로 주면, 내부에서 yt-dlp --write-thumbnail로 thumbnail JPG만 받아 Sora의 input_reference로 multipart 업로드. 일반 이미지 URL은 그대로 fetch. reference 1개당 1개의 잡으로 분할하므로 N×M(refs×prompts) 변주를 한 번에 큐잉 가능.

잡 라이프사이클

한 잡의 5단계. cancel()은 OpenAI 측 cancel endpoint로 위임.
